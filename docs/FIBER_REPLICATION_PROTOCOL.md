# Replication across the remaining primary training seeds

The seed-zero paired certificates demonstrate a property of four saved models.
They cannot establish repetition across independently trained seeds. This
extension fixes the same four gamma values and includes every remaining original
primary seed, 1 through 9, before constructing the new readouts or evaluating
their continuum certificates. There are 36 models and 144 specified circles.

The full recorded design is `configs/fiber_replication_v1.json`. Original sampled
metrics across these seeds were already available, so this is an exploratory
replication protocol for new verification outcomes, not a preregistration of the
original research. No new models are trained and no checkpoint is retuned.

Each model receives the original affine-readout fit and sampled derivative
screen. A failed screen prevents using that fixed witness as a retention proof;
it does not establish loss of injectivity. Every decision domain is tested,
including models with failed retention screens. Exact paired claims require
both positive certificates on the same checkpoint, embedding and theta.

The numerical verifier cores and property budgets are unchanged. A positive
decision margin is deterministically halved before publishing the replication
claim, with integer floor at denominator 2^64 and a strict-positive check. This
buffer is specified before new outcomes, following the documented Mac/Linux
enclosure discrepancy in the seed-zero study. It changes neither the scientific
correct-class property nor its domain. There is no adaptive margin search.

All models, circles, statuses, sources and replay outcomes remain visible. Report
successes per specified circle and models succeeding on all four circles;
independent replication units are the nine training seeds. The four circles in
one model are not independent seed replicates. The seed-zero discovery cohort
stays separate from these results. This extension tests repeatability, not a
new general possibility of information-preserving classification, which already
has prior art. Full-torus robustness and high novelty are not assumed.
